# portfolio

Portfólio pessoal de desenvolvedor web — Next.js, TypeScript e Tailwind CSS, com projetos reais, case studies e design dark premium.

🔗 [marciosouza.dev](https://marciosouza.dev)

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com)
- [Motion](https://motion.dev) para animações
- [Lucide](https://lucide.dev) para ícones

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Estrutura

```
src/
  app/            rotas e metadata (SEO, sitemap, robots, OG image)
  components/     componentes de layout, seções e projetos
  data/           projetos, stack e configuração do site
  lib/            utilitários
```

Projetos são editados em [`src/data/projects.ts`](src/data/projects.ts).
